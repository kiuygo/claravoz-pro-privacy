ClaraVoz Pro

Privacy Policy / Política de privacidad

Last updated / Última actualización: October 18, 2026

English

ClaraVoz Pro improves the intelligibility, clarity, and volume consistency of voices played in the browser tab selected by the user.

Data collection

ClaraVoz Pro locally handles the audio samples of the media selected by the user solely to provide voice enhancement. It does not collect, record, sell, transmit, or share this website content or any personal data. It uses no analytics, advertising, trackers, or developer-operated servers.

Audio is processed locally and in real time inside Chrome. It is not recorded, retained, or transmitted outside the device.

Local preferences

The selected sound profile and control values are stored locally using chrome.storage.local. These preferences do not contain browsing history or played content and are not transmitted to the developer or third parties.

Permissions

  • activeTab: provides temporary access only to the tab selected by the user.
  • scripting: loads the packaged local audio processing engine in that tab.
  • storage: retains the user's audio preferences locally in the browser.
  • Optional website access (http://*/* and https://*/*): when explicitly approved by the user, allows the packaged local audio engine to run inside embedded player frames hosted on a domain different from the page.

This optional access is requested only after ClaraVoz cannot reach an embedded player and the user presses Enable universal compatibility. It is used solely to locate the active media element and locally process its audio. ClaraVoz does not inspect unrelated page text, retain or transmit audio, or collect URLs, browsing history, form data, or communications.

Optional support links

ClaraVoz Pro includes visible, optional links to Mercado Pago and PayPal. These sites open only after an explicit click. Contributions are never required to install, use, or update the extension. Payments take place entirely outside ClaraVoz Pro, which does not collect, receive, store, or access names, accounts, payment amounts, card details, or other financial information.

Remote code and third parties

The extension does not load or execute remote code. It does not send audio, preferences, browsing activity, or website content to payment providers or any other party.

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

For privacy or support inquiries, use the verified developer contact shown on the ClaraVoz Pro Chrome Web Store listing.

Español

ClaraVoz Pro mejora la inteligibilidad, claridad y estabilidad del volumen de las voces reproducidas en la pestaña del navegador elegida por el usuario.

Recopilación de datos

ClaraVoz Pro trata localmente las muestras de audio del medio elegido por el usuario únicamente para mejorar la voz. No recopila, graba, vende, transmite ni comparte este contenido del sitio ni datos personales. No utiliza analítica, publicidad, rastreadores ni servidores administrados por el desarrollador.

El audio se procesa localmente y en tiempo real dentro de Chrome. No se graba, conserva ni transmite fuera del dispositivo.

Preferencias locales

El perfil de sonido y los controles elegidos se guardan localmente mediante chrome.storage.local. Estas preferencias no contienen el historial de navegación ni el contenido reproducido, y no se transmiten al desarrollador ni a terceros.

Permisos

  • activeTab: proporciona acceso temporal únicamente a la pestaña elegida por el usuario.
  • scripting: carga en esa pestaña el motor local de audio incluido en el paquete.
  • storage: conserva localmente las preferencias de audio del usuario.
  • Acceso opcional a sitios web (http://*/* y https://*/*): cuando el usuario lo aprueba expresamente, permite que el motor local incluido se ejecute dentro de reproductores integrados alojados en un dominio diferente al de la página.

Este acceso opcional solo se solicita después de que ClaraVoz no logra alcanzar un reproductor integrado y el usuario pulsa Activar compatibilidad universal. Se utiliza únicamente para localizar el elemento multimedia activo y procesar su audio localmente. ClaraVoz no inspecciona texto ajeno al reproductor, no conserva ni transmite audio y no recopila direcciones URL, historial de navegación, datos de formularios o comunicaciones.

Enlaces de apoyo opcionales

ClaraVoz Pro incluye enlaces visibles y opcionales a Mercado Pago y PayPal. Solo se abren tras una pulsación explícita. Ningún aporte es necesario para instalar, utilizar o actualizar la extensión. Los pagos ocurren íntegramente fuera de ClaraVoz Pro, que no recopila, recibe, almacena ni consulta nombres, cuentas, importes, tarjetas u otra información financiera.

Código remoto y terceros

La extensión no carga ni ejecuta código remoto. No envía audio, preferencias, actividad de navegación ni contenido de sitios web a proveedores de pago ni a ningún tercero.

El uso de información recibida de las API de Google cumple la Política de Datos de Usuario de Chrome Web Store, incluidos los requisitos de Uso Limitado.

Contacto

Para consultas de privacidad o soporte, utiliza el contacto verificado del desarrollador que aparece en la ficha de ClaraVoz Pro en Chrome Web Store.
